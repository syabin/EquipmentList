# 设备清单制作工具

## 项目概述

这是一个用于工业设备清单管理的Web工具，帮助工程师快速创建、编辑和管理设备清单。

**核心价值**：将传统的Excel设备清单转化为结构化的Web表格，支持智能搜索、批量操作、工时统计等功能，大幅提升工作效率。

---

## 主要功能

### 1. 设备清单编辑
- 表格式编辑，支持20+字段
- 行拖拽排序（Ctrl+拖拽=复制）
- 批量删除、批量填充
- **工序批量修改**：勾选多行后点表头「工序 ▾」，可覆盖全部 / 仅填空 / 清空，支持点击表中已有值快捷填入、Ctrl+Z 撤销；也可直接在任一勾选行的工序格输入，自动同步到其它勾选行（与位置/条线/项目号等列一致）
- 右键菜单操作

### 2. 型号智能搜索
- 加载成品型号对照表（Excel）
- 输入型号时自动匹配
- 自动填充设备名称、属性、部门等字段

### 3. 数据导入导出
- **导入Excel**：从已有设备清单导入
- **导出Excel**：生成带格式的Excel文件
- **合同号下拉菜单**（📄 合同号 ▾）：
  - 📄 填合同号：从RICH定单表自动填充
  - ⚡ 模拟合同号：按规则自动生成空合同号（详见下方"模拟合同号规则"）
  - 🗑 清除合同号：二次确认后清空全部合同号

### 4. 工时统计
- 内置计时器
- 记录工作时间
- 自动保存计时状态

### 5. 撤销/重做
- 支持50步操作历史
- 快捷键：`Ctrl+Z` 撤销，`Ctrl+Y` 重做

## 新增功能

### 6. 项目存档系统（v2）
- 按项目名称/项目号保存配置，可加备注；同名可选「覆盖更新 / 另存为」
- 存档列表：搜索、排序（时间/名称/行数）、分页、当前存档高亮
- 单条操作：加载、编辑名称备注、复制、导出、删除（8 秒内可撤回）
- 批量操作：勾选后批量导出 / 删除（同样可撤回）、清理自动快照
- **数据安全**：写入前算体积、超 4MB 拒绝且不动原数据；加载前自动留快照；定时（15 分钟且内容有变化）自动留底，最多保留 5 份；导入做结构校验，坏数据不入库
- **导入三策略**：覆盖同 id / 换新 id 保留两者 / 跳过重复；兼容旧版 v1 存档自动迁移
- 加载存档会一并恢复：行数据、对照表、累计工时、下一行 ID，并重置筛选与重做栈
- **导出/导入存档**：JSON 文件（含 `app`、`version` 字段），导出文件名带时间戳，可备份或迁移

### 7. GitHub 云端同步
- 与「任务管理器」同款机制（Contents API + PAT），**共用私有仓库 `syabin/task-data`，但放在不同文件夹**：
  - 任务管理器：`data/task-data.json`（+ `data/attachments`）
  - 设备清单：`equipment-list/equipment-data.json`
- 同步内容：当前工作区、全部项目存档、型号对照表、累计工时（存档库与对照表可分别关闭）
- 操作：测试连接 / 上传 / 拉取 / 对比云端差异 / 强制覆盖上传 / 编辑后自动静默上传（3 秒合并一次）
- 冲突保护：上传前比对上次同步的远端 `sha`，云端被其他设备改动时**拒绝覆盖**，先看差异再决定采纳哪边
- 拉取前自动留一份本地快照；令牌只存本机（默认不落盘，勾选「记住」才存），不会写进导出文件

## 使用流程

### 首次使用
1. 打开 `index.html`
2. 点击「📋 对照表」导入成品型号对照表
3. 开始添加设备行

### 日常使用
1. 点击「+ 添加行」添加新设备
2. 在型号列输入，系统自动匹配并填充
3. 补充其他字段信息
4. 完成后点击「💾 保存」或「📤 导出」

### 工序批量修改
1. 勾选需要修改的行（表格左侧复选框，可 Shift+点击范围选择）
2. 点表头「工序 ▾」→ 输入工序值（或点表中已有值）→ 选「覆盖所有勾选行 / 仅填充空白 / 清空」→ 应用
3. 也可直接在任一勾选行的工序格输入新值，其它勾选行会同步（同位置、条线、项目号等列的批量填充）
4. 修改进入撤销历史，Ctrl+Z 可回退；开启云同步后会自动上传

### 存档管理
1. 点击「📁 存档」打开存档面板
2. 输入项目名称（可加备注），回车或点「保存」；同名会询问覆盖 / 另存
3. 存档可加载 / 编辑 / 复制 / 导出 / 删除（删除后 8 秒内可撤回）；勾选后可批量导出或删除
4. 加载前系统自动留一份当前状态快照；列表支持搜索、排序、分页
5. 使用「导出全部」备份到文件，「📥 导入」时可选覆盖 / 另存 / 跳过重复

### 云端同步（首次使用）
1. 点顶栏「☁ 云同步」，确认仓库 `syabin/task-data`、路径 `equipment-list/equipment-data.json`、分支 `main`
2. 填入 GitHub PAT（Fine-grained token，选中该私有仓库，勾选 `Contents: Read and write`）
3. 点「测试连接」→「⬆ 上传到 GitHub」建立首次同步
4. 可勾选「编辑后自动静默上传」；换设备时点「⬇ 从 GitHub 拉取」即可恢复
5. 提示冲突时先点「🔍 对比云端差异」，再决定拉取或以本地为准强制覆盖

## 模拟合同号规则

通过「📄 合同号 ▾ → ⚡ 模拟合同号」生成，**仅填充合同号为空的行**（已填的不动，可 Ctrl+Z 撤销）。年/月取当前日期。

### 特殊标识 → 英文代码
| 标记 | 代码 | 标记 | 代码 |
|------|------|------|------|
| 出口 / 医药 / 防爆 / 有毒 | F / Y / EX / D | 电控硬件 / 上位机 | EE / SE |
| 精细化工 / 出口精细化工 | -EC / F-EC | 出口电控硬件 / 出口上位机 | F-EE / F-SE |
| 精细化工电控硬件 / 精细化工上位机 | -EC-EE / -EC-SE | | |

组合规则：先取基础码（出口F、医药Y、防爆EX、有毒D、精细化工-EC、出口精细化工F-EC），再接后缀码（电控硬件EE、上位机SE，以 `-` 连接）；`普通`/空不参与。

### ROSS（业务归属=ROSS）
格式：`2位年 + 3位序列号 + 特殊标识代码 + 后缀`
- **主设备有值** → 序列号递增，不加后缀
- **主设备为空 + 配套标识有值** → 序列号沿用上一个（不增加），加 `-配套标识` 后缀
- **主设备空 + 配套标识也空** → 序列号递增，无后缀
- 例：`26001`、`26001-A`、`26002EX`

### RICH（业务归属=RICH，或非 ROSS）
格式：`2位年 + 2位月 + 4位序列号 + 特殊标识代码 + "-" + 顺序号`
- **序列号**：每条线一个固定号，按该条线首次出现顺序分配（条线1→0001、条线2→0002），仅统计 RICH 行
- **顺序号**：每条线内独立累计 1、2、3…（仅对本次补空的行计数）
- 例：`26090001EX-2`、`26090002-EC-SE-1`

## 自动编号（配套标识分组）

通过工具栏「🔢 自动编号」一键生成，按录入约定给「配套标识」列编组序号（可 Ctrl+Z 撤销）。

### 录入约定
- **主设备 = 1**：一组的起点（那台主机）
- **主设备 留空**：配套设备行，排在组起点下方
- **主设备 = 0**：独立设备（无配套）

### 编号规则
- 以「主设备=1」为一组起点，其后**连续的主设备为空**的行同属一组
- 组内序号独立从 1 开始依次增加：组起点（主设备=1）配套标识填 `1`，其下主设备为空的配套行依次为 `2`、`3`…；下一组重新从 `1` 起算（合同号 `-` 后缀因此每组从 `-1` 开始）
- 主设备=0 的独立设备、以及前面没有组起点的空主设备行，配套标识清空
- 例：
  ```
  DPD-450RC   主设备=1   配套标识=1   ← 第1组起点
  钢平台      主设备=空  配套标识=1   ← 配套
  DPD-450RC   主设备=1   配套标识=1   ← 第2组起点（组内重新从1）
  钢平台      主设备=空  配套标识=1   ← 配套
  某独立设备   主设备=0   配套标识=空  ← 无配套
  ```

### 导出
- 主设备=0 的行导出 Excel 时该列清空（不显示 0），合同号照常保留（如 `26001`）

## 注意事项

1. **数据存储**：工作区自动暂存、项目存档、对照表缓存均在浏览器 localStorage；清除浏览器数据会丢失，请定期「导出全部」或开启云端同步
2. **存档容量**：存档库上限 4MB（面板实时显示占用），超限会拒绝写入且不改动原数据；自动快照最多保留 5 份
3. **云端同步**：与任务管理器共用 `syabin/task-data` 仓库，文件路径必须保持 `equipment-list/...`，不要改成 `data/...` 以免覆盖任务管理器数据；PAT 需该私有仓库 Contents 读写权限
4. **对照表格式**：导入的Excel需要包含型号、设备名称、属性等列
5. **浏览器兼容**：推荐使用Chrome，旧版IE不支持
